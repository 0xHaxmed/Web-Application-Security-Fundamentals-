# 🧭 Room 1: Walking An Application

Welcome to the documentation suite for **Walking An Application** (TryHackMe Web Application Security Fundamentals).

This room explores manual web application reconnaissance using browser Developer Tools (DevTools) without automated scanners, examining the live DOM, temporal JavaScript debugging, background network requests, and client-side cookie storage.
