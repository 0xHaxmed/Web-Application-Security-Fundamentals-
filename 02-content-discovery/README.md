# 🔍 Room 2: Content Discovery

Welcome to the documentation suite for **Content Discovery** (TryHackMe Web Application Security Fundamentals).

This room explores the tri-layer reconnaissance model: Manual Discovery (`robots.txt`, `sitemap.xml`, headers), OSINT (Google Dorking, Wayback Machine, GitHub, S3 Buckets), and Automated Discovery with Gobuster (`dir`, `dns`, and `vhost` modes).
