# 🖥️ Room 4: Web Server Attacks - I

Welcome to the documentation suite for **Web Server Attacks - I** (TryHackMe Web Application Security Fundamentals).

This room explores web server misconfiguration identification across four foundational Linux web servers: Apache2, Python's built-in HTTP server, Node.js (Express), and Nginx, including diagnostic modules, dotfile exposure, and security header audits.
