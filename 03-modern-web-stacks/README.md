# ⚙️ Room 3: Modern Web Stacks

Welcome to the documentation suite for **Modern Web Stacks** (TryHackMe Web Application Security Fundamentals).

This room covers passive stack fingerprinting and the targeted exploitation of four distinct real-world CVEs: Prototype Pollution in Express (CVE-2020-8203), Next.js Middleware Auth Bypass (CVE-2025-29927), Django ORM SQL Injection (CVE-2021-35042), and Apache 2.4.49 Path Traversal to RCE (CVE-2021-41773).
